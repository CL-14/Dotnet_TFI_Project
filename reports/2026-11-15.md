## Project Title and Description

Where Is That Ghost Bus?

It's a reliability-focused Dublin bus tracking web application. The project builds a C# web application (ASP.NET Core Razor pages, SQLite) on the NTA's open GTFS and GTFS-Realtime data. It will show live bus positions and service alerts and can also estimate service reliability by comparing scheduled trips with the vehicles actually observed.

---

## Progress This Week

* **US19 (continuous data collector) & US21 (clear API error handling) — First version complete:** The collector polls the NTA vehicle, trip-update, and alert feeds within the usage limit (one request per minute in total), stores per-trip history, live vehicle positions, and current alerts in SQLite, and logs every poll. Failures are handled by type (rate limit, rejected key, timeout, connection error) without stopping the loop.
* **Production Deployment:** The collector has run in Docker on a home server since 12 November, complete with a restart policy, a nightly backup (checked and copied off the server), and a health-check script. It has made about 4,000 polls, with 3 transient failures, all logged.
* **Core Persistence & Testing:** Database writers for all five tables, the feed mappers, and a fix for the NTA alert period field (the feed still fills the deprecated `active_period` field on all 45 alerts checked, so the code reads the newer field first and falls back to the old one), each with automated tests. All merged.
* **Infrastructure:** Remote access to the server set up over Tailscale.
